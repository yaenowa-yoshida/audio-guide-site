プライバシーポリシー（草案）

本アプリは現在、試験版（β）を試験配布しています（提供中の正式な サービスではありません）。この文書はその試験配布に適用される草案であり、 機能の追加・変更にあわせて改訂します。確定版は正式公開時に、 改訂履歴つきでこのページに掲示します。

1. 位置情報

本アプリは、現在地のまわりの話題を選び、距離と方角を読み上げるために 位置情報を利用します。この処理はすべて端末内で行われ、 本アプリが現在地・移動履歴を外部のサーバーへ送信することはありません。 本アプリには送信先となる自前のサーバーが存在しません。

なお、測位そのもの（GPS・Wi-Fi・基地局による位置推定）は OS が提供する仕組みを 利用しており、その過程で OS の提供元が通信を行うことがあります。これは本アプリの 制御の外にあり、各 OS 提供元のプライバシーポリシーが適用されます。

2. 音声の読み上げ

読み上げる文には現在地から計算した距離・方角が含まれます。このため本アプリは、 端末内で処理される音声合成だけを使用します。端末内で合成されることが 確認できない場合、本アプリは読み上げを行いません。読み上げ文が音声合成の 事業者へ送られることはありません。

3. 端末内に保存するデータ

再生済みの話題の記録と、利用者が選んだ設定（移動手段など）を端末内にのみ 保存します。これらは端末の外に出ません。アプリ内の操作でいつでも削除できます。

4. 広告について

本アプリは、広告の表示のために Google AdMob の SDK （react-native-google-mobile-ads）を含みます。広告が表示されるのは 案内をしていない待機画面のバナー 1 か所だけで、 案内中の画面や読み上げ音声に広告が入ることはありません。

本アプリは広告 SDK に位置情報を渡しません。位置情報に連動した 広告は使用しません。また、広告はパーソナライズなし（interest-based でない配信）を既定として要求しています。

広告の配信にあたり、Google が広告 ID（Android の advertising ID 等）や 端末情報を取得・利用することがあります。その取り扱いは Google のポリシー（パートナーサイト・アプリでのデータ使用）に従います。 広告 ID は端末の設定（Android:「設定 → プライバシー → 広告」）から リセット・削除できます。

現在の試験版では、動作確認のためのテスト広告（配信確認用の 表示で、実際の広告主の広告ではありません）を表示しています。実際の広告配信を 始める際は、この章を改訂したうえで切り替えます。

5. 収集しないもの

本アプリは、上記の広告 SDK を除き、アクセス解析・行動計測の SDK を含みません。 アカウント登録もなく、氏名・連絡先等の個人情報を取得しません。 収集の内容が変わる場合は、導入前に本ポリシーを改訂し、 収集内容・提供先・同意の方法を明記します。
